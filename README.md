# Public Android Lab

This repository is a collection of my public software projects, experiments, and reusable components.

Most of the work here is focused on Android development, Kotlin, Jetpack Compose, app architecture, UI components, and practical developer utilities. Some projects may be complete libraries, while others are smaller experiments or learning projects.

You are welcome to explore the code, review the implementation, open issues, or reuse anything that fits your own work.
